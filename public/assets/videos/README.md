# Videos

No video files were supplied in the original archive and none were fabricated.

- Hero video: add `hero.mp4` (H.264, ≤ 8 MB, muted loop, ~1920×1080) + `hero-poster.jpg`, then set
  `heroVideo: '/assets/videos/hero.mp4'` and `heroPoster: '/assets/images/hero-poster.jpg'` in `src/config/site.js`.
- Project hover previews: add an MP4 and set `video: '/assets/videos/<file>.mp4'` on a project that also has a `cover`.
