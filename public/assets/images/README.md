# Images

- `illustrations/` — line-art illustrations reused from the previous site (converted to WebP).
- `projects/` — **drop project screenshots here** (`<slug>.jpg`, ~1600×1200, optimised < 250 KB), then set
  `cover: '/assets/images/projects/<slug>.jpg'` for that project in `src/data/projects.js`.
  Until then a generated typographic cover is displayed (nothing is broken or missing).
- Founder portrait: add a file here and set `SITE.founder.photo` in `src/config/site.js`.
