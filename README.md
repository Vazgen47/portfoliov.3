# Mkheyan Agency — website

Premium bilingual (Armenian / English) agency website.
**React 18 · Vite 5 · Tailwind CSS 3 · GSAP + ScrollTrigger · Lenis · Framer Motion · Lucide**

> **Status note.** This project was authored in an environment without internet access, so
> `npm install` / `npm run build` could **not** be executed there. Source files were verified
> with esbuild (syntax + import resolution) and `npm run check`, but the first real install and build
> happen on your machine. If anything fails, see *Troubleshooting* at the bottom.
> `package-lock.json` is not included for the same reason — `npm install` creates it; commit it afterwards.

## 1. Requirements

- Node.js **18.18+** (20 or 22 LTS recommended) and npm 9+
- Git (for GitHub deployment)

## 2. Install & run

```bash
npm install          # installs dependencies and creates package-lock.json
npm run dev          # dev server  -> http://localhost:5173
npm run build        # production build -> dist/   (also regenerates public/sitemap.xml)
npm run preview      # serves dist/ locally -> http://localhost:4173
npm run check        # offline sanity check: imports, declared deps, asset paths
```

## 3. Environment variables

Copy `.env.example` to `.env`. Only needed for the contact form (see §8). **Never commit `.env`.**

## 5. Editing content

| What | Where |
| --- | --- |
| Email, social links, founder, WorkMark URL, hero video | `src/config/site.js` |
| UI text (both languages) | `src/i18n/en.js` and `src/i18n/hy.js` — keep keys identical. Wrap words in `*asterisks*` inside headings to colour them green. |
| Projects | `src/data/projects.js` (add an object; it appears in the grid, filters, detail pages and sitemap) |
| Services / process steps | `src/data/services.js`, `src/data/process.js` |
| Articles | `src/data/insights.js` (add an object with `{type:'p'|'h2'}` body blocks) |
| Colours | CSS variables at the top of `src/styles/index.css` |

Content rules used in this build: no invented clients, awards, testimonials, statistics or results.
The 12 projects, roles and stacks come from the previous site archive. **Please double-check each project is
approved for public showcase.** The body of the article *“Infusing Production Web Applications with AI…”*
was newly written (the original archive contained a copy of the first article) — review it before publishing.

## 6. Images and videos

- **Project screenshots:** save as `public/assets/images/projects/<slug>.jpg` (≈1600×1200, < 250 KB), then set
  `cover: '/assets/images/projects/<slug>.jpg'` in `src/data/projects.js`. Until then a generated typographic
  cover is shown, so nothing is broken.
- **Hero video:** add `public/assets/videos/hero.mp4` (+ poster) and set `heroVideo` / `heroPoster` in `site.js`.
  Until then the generative canvas animation is used.
- **Project hover video:** set `video` on a project that also has a `cover`.
- **Founder portrait:** set `SITE.founder.photo` in `site.js`.
- Media is lazy-loaded; keep videos short (≤ 8 MB) and muted.

## 7. Languages & SEO

- Armenian is served at `/…`, English at `/en/…`. The header switcher links to the equivalent page and remembers an
  explicit English choice (localStorage) for future visits.
- `src/hooks/useSeo.js` sets per-page title, description, canonical, hreflang (`hy`, `en`, `x-default`), Open Graph,
  Twitter Card, robots and JSON-LD (Organization + ProfessionalService, Person, WebSite, BreadcrumbList, Article,
  CreativeWork). **No ratings or reviews are published** in structured data.
- `public/sitemap.xml` is generated by `scripts/generate-sitemap.mjs` on every build. `robots.txt` points to it.
- Search-console verification files/tags from the old site were preserved (`googleb711e076c105fba0.html`,
  Bing + Yandex meta tags in `index.html`).
- **SPA limitation:** metadata is applied by JavaScript (Googlebot executes it). Crawlers that do not run JS see the
  default Armenian homepage metadata in `index.html`. For maximum SEO, add pre-rendering later (e.g. `vite-plugin-prerender`
  or migrate to Next.js) — the data/i18n layers are framework-agnostic.
- Unknown URLs show the in-app 404 with `noindex`, but a static host returns HTTP 200 for them (soft-404).

## 8. Contact form

The form validates input, has loading/success/error states and **never reports success unless delivery succeeded**.
Configure one integration in `.env`:

**A. Firebase (the previous site used project `mkheyan-agency`)** — fill `VITE_FIREBASE_*`. Messages are written to the
`contactMessages` collection. Use strict Firestore rules, e.g.:

```
rules_version = '2';
service cloud.firestore {
  match /databases/{db}/documents {
    match /contactMessages/{id} {
      allow create: if request.resource.data.keys().hasOnly(['name','email','service','message','lang','createdAt','source'])
                    && request.resource.data.name is string && request.resource.data.name.size() < 200
                    && request.resource.data.email is string && request.resource.data.email.size() < 200
                    && request.resource.data.message is string && request.resource.data.message.size() < 5000;
      allow read, update, delete: if false;
    }
  }
}
```

**B. HTTP endpoint** — set `VITE_CONTACT_ENDPOINT` to any HTTPS URL accepting a JSON `POST`.

With neither configured the form shows an error with a mailto fallback (`mkheyanagency@gmail.com`).

## 9. Deployment

### GitHub
```bash
git init && git add . && git commit -m "Mkheyan Agency website"
git branch -M main
git remote add origin https://github.com/<you>/mkheyan-agency.git
git push -u origin main
```
`.gitignore` already excludes `node_modules`, `dist` and `.env`. Add `package-lock.json` after your first `npm install`.

### cPanel (static hosting — recommended)
1. `npm run build` locally.
2. Upload the **contents** of `dist/` to `public_html/` (File Manager or FTP). `dist/` already contains `.htaccess`
   (SPA rewrite, caching, compression) — make sure hidden files are uploaded.
3. Enable HTTPS (AutoSSL) and optionally uncomment the HTTPS redirect in `.htaccess`.
4. Environment variables are baked in at build time — set `.env` **before** `npm run build`.

### cPanel "Setup Node.js App" / any Node host
Static hosting is enough. If you want Node to serve it: `npm run build && npx serve -s dist -l $PORT`
(`-s` = SPA fallback). On Netlify/Vercel/Cloudflare Pages: build command `npm run build`, output `dist`, with an SPA
fallback rule to `/index.html`.

## 10. Accessibility & performance notes

- `prefers-reduced-motion`: Lenis, scroll animations, the hero canvas loop and the page curtain are disabled.
- Skip link, semantic landmarks, keyboard-operable menu (Esc closes, focus returns), accordion with ARIA, form errors with
  `aria-invalid` / `role="alert"`.
- Fonts are self-hosted via `@fontsource`; Firebase is code-split and loaded only when the form is submitted.
- The Process section pins and scrolls horizontally on screens ≥ 1024 px; on smaller screens it is a vertical list.
- A custom cursor was intentionally not added (it would not improve usability).

## Troubleshooting

- **`Cannot find module '@fontsource/...'`** — run `npm install` again; if a font import path differs in the installed
  version, check `node_modules/@fontsource/<family>/` for the available `*.css` files and update `src/main.jsx`.
- **Blank page after upload** — hidden `.htaccess` was not uploaded, so deep links 404.
- **Port in use** — `npm run dev -- --port 3000`.
